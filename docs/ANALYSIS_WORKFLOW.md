# AI 동의·시작·진행·복구 UI

2026-09-18. C1의 동의와 실행 상태 UI를 로컬에 구현하고 합성 자료·모의 AI로 검증했다. **제품 서버의 새 AI 실행은 여전히 차단되어 있다.** 체크박스나 환경 변수로 실행 조건을 우회하지 않는다. 기존 기준 `DEVELOPMENT_PLAN.md`는 수정하지 않았다.

## 구현 범위

- 편집기에 전송 대상·비용·취소 한계를 설명하는 안내 창을 추가했다. 두 확인란은 열 때마다 해제되며, 명시적인 시작 클릭과 현재 저장본 일치가 필요하다. 현재 서버가 준비되지 않았으면 모두 체크해도 시작할 수 없다.
- Google Gemini에 보내는 대상은 원본 영상/음성이 아니라 **전체 원본 추출 장면**, 순서·시각·크기와 생성 지시문임을 알린다. 토큰 계산에도 이미지가 전달되며, 편집에서 삭제/병합한 장면도 포함되고 화면 위 표시·가림이 이미지에 반영되지 않음을 명시했다. 현재 제목·제작 의도·직접 작성한 설명은 분석 입력에 포함하지 않는다.
- 무료 서비스의 데이터 이용/사람 검토 가능성을 알리고 개인·민감·기밀 정보가 없는 승인된 합성 자료로 제한한다. [Google Gemini 무료 서비스 조건](https://ai.google.dev/gemini-api/terms#unpaid-services)을 연결했다. 무료 전용 실행 조건과 앱 한도는 Replit 처리/저장까지 무료라는 약속이 아니며, 취소도 이미 보낸 데이터의 회수나 외부 처리·사용량의 즉시 중단을 보장하지 않는다.
- `GET /api/guides/:guideId/analysis/capabilities`는 소유자 인증과 영상 지문을 확인하는 읽기 전용 표시 계약이다. 현재 제품 응답은 항상 `startAvailable: false`다. 주입된 테스트 admission이 있어도 이 값은 바뀌지 않는다. 실행 허용 증거나 B5 완료로 취급하지 않는다.
- 상태 조회/시작/취소는 기존 동일 출처 API만 사용한다. 브라우저 요청에는 이미지·영상·작성 내용·Google 키를 넣지 않는다. 새 클라이언트의 시작/개별 조회/취소에는 영상 지문 헤더도 연결했다.
- 요청 ID와 최소 복구 정보만 브라우저에 먼저 저장하고 읽어 확인한 후 POST한다. 복구 정보에는 편집 키·영상·이미지·제목·설명이 없다. 저장 불가/손상/다른 영상의 기록은 새 접수를 막는다.
- 응답 유실·접수 여부 불명·조회 404는 미접수로 단정하지 않는다. 같은 ID의 상태만 확인하며 새 ID 생성·POST 재전송을 하지 않는다. 확인된 종료 상태에서만 해당 복구 기록을 해제한다. 다른 창의 기록도 임의로 지우지 않는다.
- 새로고침 시 저장된 실행을 GET으로 복구한다. 대기/실행 상태는 5초 간격, 회당 최대 24번 조회하며 숨겨진 탭에서는 멈춘다. 수동 상태 확인으로 조회를 다시 시작할 수 있고, 자동 조회 중단은 작업 취소가 아니다. 취소는 서버 응답을 확인한 뒤 완료로 표시한다.
- 저장된 편집본의 수정 번호가 0인 초기 초안에서는 시작하지 않는다. 기존 서버가 초기 초안에 한해 결과를 자동 반영하는 계약과 충돌하지 않도록, 이 UI는 수정 번호가 1 이상인 저장본에서만 시작을 요청한다.
- 결과는 편집을 자동으로 변경하지 않는다. 기존 [결과 검토·선택 적용](ANALYSIS_RESULT_REVIEW.md)에 연결했고, 선택한 단계만 기존 충돌 방지 자동 저장을 거쳐 반영한다.

## 검증

- 일반 전체 회귀 761개(이관 91 + API 587 + 클라이언트 83), 실패·생략 0. 신규 API 2개와 클라이언트 15개를 포함한다. 마지막 초기 초안 차단 보완 뒤 클라이언트 83개를 다시 실행해 통과했다.
- API/ShowMe의 제품·테스트 타입 검사 4종과 두 제품 빌드 통과. 화면 빌드의 기존 소스맵 경고와 558.36 kB 번들 크기 경고는 남는다. 기존 Windows 네이티브 보조 도구와 필요한 로컬 경로 권한을 사용했으며 추가 설치나 잠금 파일 변경은 없다.
- 별도 로컬 인앱 브라우저와 루프백 서버에서 실제 합성 영상 업로드·FFmpeg·HTTP·JSON 저장소를 사용했다. 외부 AI 클라이언트는 만들지 않았고 모의 provider만 사용했다. 검증 서버의 외부 fetch는 거부하고 페이지 연결 대상도 CSP로 같은 출처에 제한했다. 이것을 운영 환경 전체의 네트워크 감사로 주장하지 않는다.
- 제품의 차단 응답에서 확인란 2개를 체크해도 시작 불가를 확인했다. 별도 모의 서버에서만 준비 응답을 제공하여 체크 0개/1개 차단, 체크 2개 후 명시적 시작, 새로고침 복구, 취소를 확인했다. 이 모의 응답 우회는 제품 코드에 없다.
- 서버가 접수한 뒤 응답을 끊는 모의 장애에서 불확정 안내를 확인했다. 새로고침 뒤 같은 대기 작업이 복구됐고 접수 횟수는 2회 그대로였다(앞선 취소 검증 1회 포함). 중복 POST가 없었다.
- 실행 대기 중 직접 작성한 설명은 모의 성공 후에도 유지됐다. 결과 창의 기본 선택은 0개였고, 2단계만 적용한 뒤 자동 저장·새로고침해 1단계의 직접 작성 내용과 3단계가 보존됨을 확인했다.
- 세 번째 명시적 모의 실행은 실패시켰다. 실패 안내와 편집 유지, 자동 재실행 없음, 총 접수 3회·취소 1회를 확인했다. 성공/실패 처리 전후 서버 초안 동일성도 검사했다.
- 1440px 배치와 320/390px 동의 창을 확인했다. 작은 화면에서 가로 넘침 없이 안내/확인란/하단 버튼에 스크롤로 접근할 수 있고 키보드 조작이 된다. 임시 화면 크기 설정은 복원했다.
- 브라우저 검증 보조 서버는 상위 작업 폴더 `outputs/replit-ui-runtime/analysis-workflow-server.mjs`와 `run-analysis-workflow.mjs`에 있다. 임시 합성 저장 폴더 두 개를 정리했다. 개인 Chrome 프로필·Replit·Google 계정이나 개인 영상에는 이번 검증으로 접근하지 않았다.

## 남은 범위

이번 변경은 로컬 구현·검증까지다. GitHub push나 Replit 반영/재시작은 이번 검증에 포함하지 않는다. 실제 실행 조건과 dispatcher 연결(B5), Replit에서의 회귀, 개인정보 탐지 품질·영구 가림·공개 공유는 별도 작업이다. [실행 조건 기록](ANALYSIS_READINESS.md)의 차단을 풀지 않았다. 실제 PostgreSQL 계약이나 스키마를 변경하지 않아 별도 DB 실검사는 재실행하지 않았다.

응답이 계속 불확정이거나 복구 기록이 손상된 경우 안전하게 새 실행을 막으며 자동으로 기록을 버리지 않는다. 이 경우의 사용자 지원/정리 절차는 실제 실행 활성화 전에 별도로 정해야 한다. 개인 영상을 Gemini로 보내도 된다는 승인을 이번 UI 구현으로 간주하지 않는다.

## 2026-09-19 — 고객용 안내 문구 정리

- 사용자 요청에 따라 기능 이름을 `ShowMe AI`로 소개하고, 동의 창의 설명·확인란에서 모델 상품명과 호스팅 브랜드를 뺐다. 처리업체 **Google**, 전송 대상, 데이터 이용 조건을 숨기거나 자체 처리만 하는 것처럼 표현하지 않는다. 공식 처리 조건 링크는 유지한다.
- 전체 원본 화면 전송, 삭제/병합된 장면 포함, 가림 미반영, 제품 개선 이용/사람 검토 가능성, 민감 정보 금지, 합성 자료 제한, 취소 후 데이터 회수 불가와 결과 수동 적용은 처음부터 표시한다. 세부 전송 항목·비용·취소 처리 설명만 키보드로 펼칠 수 있는 `자세히 보기`에 배치했다.
- 개인정보 핵심 안내가 접힌 영역 밖에 남는지, 모델·호스팅 브랜드가 문구에 재등장하지 않는지, 상세 항목과 공식 링크를 유지하는지, 화면 수 미확인을 0장으로 표시하지 않는지 회귀 검사 3개를 추가했다.
- 이번 실행은 클라이언트 86개, ShowMe 제품/테스트 타입 검사 2종, 화면 빌드가 통과했다. 앞선 전체 761개 검사와 구분하며 이번에는 서버/이관 전체를 다시 실행하지 않았다. 기존 소스맵 경고와 559.04 kB 번들 경고는 남는다.
- 별도 로컬 합성 가이드로 320px/1440px 표시, 상세 내용 키보드 펼치기, 동의 두 항목 체크 후에도 실행 차단, 닫았다 열 때 체크 해제를 확인했다. 브라우저 오류 0, 분석 접수 0이며 실제 AI 전송은 없다. 임시 화면 크기 설정을 복원하고 검증 탭·서버와 해당 실행의 임시 합성 데이터를 정리했다.
- 기존 기준 MD, 서버 실행 조건, 전송 경로, 실제 AI 모델 설정은 바꾸지 않았다. GitHub push와 Replit 반영은 아직 하지 않았다.

ShowMe Replit 작업본은 `3701e9b`의 같은 브랜치이고 별도 수정이 없음을 확인했다. 이 기록은 반영 전 검사이며, 실제 Replit 반영·실행 검증 결과와 구분한다.
