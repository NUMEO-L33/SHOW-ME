# 저장된 AI 결과 검토·선택 적용

2026-09-18. C1의 **결과 조회·검토·편집 반영** 부분을 로컬에 구현했다. 새 AI 접수·동의·자동 실행은 활성화하지 않았다. Replit에서 성공한 독립 합성 진단 결과를 사용자 가이드에 임의로 끼워 넣지 않는다.

## 동작

- 편집 화면의 `저장된 AI 결과 확인`은 사용자가 누를 때만 같은 출처 서버에 GET 한 번을 보낸다. 주기적 조회·재시도·이미지/영상 전송·Google 호출은 없다.
- 새 소유자 전용 `GET /api/guides/:guideId/analysis`는 bearer 인증과 `X-ShowMe-Input-Fingerprint`로 열린 초안의 영상과 대조한다. 비동기 조회 뒤 소유권·영상 상태를 다시 확인한다. 현재 영상의 마지막 실행만 돌려주며 실행 생성·예산 예약·이미지 읽기를 하지 않는다. 쿼리 문자열은 받지 않는다.
- 저장된 실행 없음/대기/진행/실패/취소는 구분해 표시한다. 성공 결과만 현재 문구와 비교하고 기본 선택은 0개다. 창을 닫으면 변경하지 않는다.
- 선택한 **합치지 않은 단계**의 짧은 제목·설명·클릭 위치만 교체한다. 가이드 제목·제작 의도·순서·삭제·병합·기존 가림 요소는 유지한다. AI의 자동 병합/개인정보 후보는 적용하지 않으며 `privacyReview: pending`을 유지한다. 위치가 없으면 이전 클릭 표시를 제거하고 임의 좌표를 만들지 않는다.
- 검토 중 현재 초안/수정 번호가 바뀌면 적용하지 않는다. 다른 창의 저장은 기존 PUT의 수정 번호·영상 지문 충돌 검사로 막는다. 충돌하면 사용자가 선택한 로컬 편집은 유지하고 자동 재시도를 중단한다. 적용 알림은 저장 성공을 주장하지 않으며 기존 `자동 저장됨` 확인을 요구한다.
- 320px 화면에서 발견한 기존 단계 목록의 가로 넘침을 기본 1열 그리드로 수정했다. 검토 창도 화면 안에서 스크롤된다.

## 검증

- 최종 일반 전체 회귀: 742개(이관 91 + 서버 583 + 클라이언트 68), 실패·생략 0, 종료 코드 0. 외부 주소/미리 취소된 조회의 네트워크 0회 검사까지 포함한다. 서버 4개·클라이언트 11개가 이번 신규 검사다.
- API와 ShowMe 제품/테스트 타입 검사, 두 제품 빌드 통과. 화면 빌드의 기존 소스맵 경고와 543.52 kB 번들 경고는 남는다.
- 독립된 로컬 headless Chrome에서 실제 합성 영상 업로드/FFmpeg/HTTP/JSON 저장소를 사용했다. **AI 출력만 모의 값**이다. 빈 결과의 읽기 전용 조회, 키보드 선택, 선택 적용→자동 저장→새로고침, 다른 창의 충돌/무재시도, 병합 보존, 잘못된 응답 거부와 320/390/768px 화면을 확인했다. 외부 요청·AI 신규 접수·페이지 오류 0이다.
- 첫 일반 서버 실행은 로컬 FFmpeg 경로 누락으로 실패했고 기존 바이너리를 테스트 전용 경로로 지정한 뒤 전체 통과했다. 빌드도 기존 Windows 네이티브 보조 도구와 필요한 경로 권한을 사용해 통과했다. 새 설치·잠금 파일·운영 바이너리 기준·제한 시간은 바꾸지 않았다.
- 브라우저 스크립트와 화면 기록은 상위 작업 폴더 `outputs/replit-ui-runtime/analysis-review-browser.mjs`, `outputs/analysis-review-ui-check/`에 있다. 새 브라우저 프로필만 사용했고 각 실행의 임시 합성 저장소는 정리했다. 개인 Chrome 프로필·Replit·Google 계정에는 접근하지 않았다.

## 아직 하지 않은 것

검증한 코드를 기존 보완 브랜치에 반영하는 단계이며, Replit 실행 확인은 아래 별도 기록으로 구분한다. 기존 readiness·한도·비공개 목적지 차단·동의 계약은 유지한다. 개인 영상 외부 전송, 추가 Gemini 실호출, 동의/새 분석 시작·진행 복구 전체 UI, 운영 실행 조건 연결, 개인정보 탐지 품질/영구 가림·공개 공유는 완료가 아니다. 실제 PostgreSQL 검사는 저장 계약을 바꾸지 않아 이번에 재실행하지 않았다.
