# 게시·공유 관리와 공개 뷰어 — 2026-09-22

원래 개발 MD의 목표·완료 조건은 변경하지 않았다. 기존 소유자/공개 HTTP와 게시 실행기에 화면을 연결했다. 기본 서버 bootstrap은 여전히 실행기를 주입하지 않으며, **Replit 운영 공개 기능을 켜거나 배포한 것이 아니다.**

## 편집기

- 실제 영상 편집기의 `게시·공유 관리`에서 현재 상태·진행·확정 링크·고정 만료·공유 중지를 확인한다. 편집 불가/보관 만료 등 실패 화면에서도 소유자 자격이 남으면 조회와 공유 중지에 접근할 수 있다.
- 새 게시에는 서버 저장 완료, 현재 revision/input의 모든 화면·문구·제목 직접 확인, 서버 접수 가능 상태, 별도의 공개 동의가 필요하다. 편집/IME/저장 실패/충돌/불러오기 중에는 차단한다. 개인정보 확인은 자동 안전 판정이 아니다.
- 원본 공유는 항상 false다. 링크를 아는 누구나 볼 수 있음, 첫 게시+15일, 재게시해도 기간 미연장, 이미 내려받은 자료는 회수 불가를 설명한다.
- 게시 요청 UUID를 해당 가이드의 브라우저 기록에 먼저 저장하고 읽어 확인한 뒤 한 번만 POST한다. 저장 불가/다른 탭의 미확인 기록은 새 게시를 막는다. 응답 유실·404 뒤에도 같은 UUID를 조회하며 자동 재게시/새 ID 생성은 하지 않는다. 끝난 동일 요청이 확인되면 자기 기록만 해제한다. 실제로 접수되지 않은 미확인 요청의 운영 해소는 아직 별도 과제다.
- 중지는 화면에서 관측한 head version/job ID를 그대로 전송한다. 충돌/불확실 실패 뒤 최신 값으로 몰래 재시도하지 않으며 사용자가 상태를 다시 확인한다. 생성 중 2초, 열린 창의 활성 공유 15초 및 만료 시점에 읽기 전용 조회한다.
- 제목 등 편집은 기존 공개본을 바꾸지 않는다. 재확인·재게시가 따로 필요하다. `편집 미리보기`는 비공개 원본임을 표시하며 공개 링크의 처리본과 구분한다. 예시 화면의 버튼은 실제 공유 완료/가짜 링크가 아닌 인앱 예시 미리보기로 이동한다.

## 공개 경로

- `/g/:slug`는 기존 localStorage/예시 fallback 대신 `/api/public/guides/:slug`의 확정 게시본만 읽는다. private draft·edit token을 읽거나 원본 경로로 대체하지 않는다.
- 공개용 GET transport를 분리했다. private credential 요청 허용 경로는 기존 `/api/guides`로 유지한다. 공개 경로도 같은 출처, redirect 거부, no-store, no-referrer다.
- 응답 필드·UUID·단계별 순번·해당 slug/publication ID의 정확한 이미지 경로·크기·시간을 검증한다. JSON 128KiB, PNG 13MiB 한도를 두고 실제 바이트 수를 확인한다. 미확인 이미지/404/오류에서는 원본이나 예시를 보여주지 않는다.
- 현재 단계 이미지 하나만 읽는다. 이전/다음·완료·처음부터·확대/스크롤·방향키 이동을 제공한다. 확대는 첫 클릭 위치 중심이며 클릭이 없으면 중앙을 사용한다. 본문 설명 22px, 주요 버튼 44px 이상이다.
- 화면 재진입/포커스·15초 간격·이미지 전환에서 서버 접근 조건을 다시 확인한다. 만료 시 내용을 비우고, 조회 실패나 이미지 실패도 안내로 전환한다. 철회 전에 내려받은 파일/캡처까지 회수한다는 보장이 아니다.

## 검증

- 일반 전체 **1,043개**: 이관 99 / 서버 828 / 클라이언트 116, 실패·취소·생략 0. 새 클라이언트 12개는 정확한 확인/저장 조건, 중복 클릭, 기록 실패, 응답 유실/재접속, 충돌, 늦은 완료, 공개 DTO/URL/크기/PNG/철회 경계를 검사한다.
- 화면 제품·테스트 TypeScript 검사와 production 빌드 통과. Windows 선택 의존성 누락은 기존 설정/잠금 파일을 바꾸지 않고 `tmp/ui-native-20260922`에 설치한 `@rollup/rollup-win32-x64-msvc@4.63.1`, `@tailwindcss/oxide-win32-x64-msvc@4.3.3`, `lightningcss-win32-x64-msvc@1.32.0`을 해당 빌드의 NODE_PATH에만 추가해 검증했다. 약 601KB JS 청크 경고와 기존 UI 파일 sourcemap 경고는 남아 있다.
- 브라우저에서 실제 소유자 HTTP → 실제 로컬 PNG 준비/게시 → 별도 탭 공개 조회 → 확대/다음 이동 → 제목 편집 시 재확인 요구/이전 게시본 유지 → 공유 중지 → 기존 링크 거부를 확인했다. 1280×800, 393×852 및 기본 좁은 창에서 레이아웃을 확인했다. 실제 휴대폰/카카오톡 검증은 아니다.
- 이 시험은 `artifacts/api-server/scripts/check-publication-ui.ts --local-synthetic`에 `NODE_ENV=test`를 명시한 loopback 전용 fixture다. 기존 승인 합성 JPEG·일회용 JSON/LocalStorage·실제 게시 실행기를 사용하며 외부 AI, Replit DB/Storage, 개인 영상은 사용하지 않는다. 브라우저의 시험 시작 경로가 이 fixture의 가짜 편집 자격만 로컬에 넣는다. 제품 bootstrap/라우터에는 등록하지 않는다.
- 첫 브라우저 요청은 fixture 임의 포트가 CORS 목록에 없어 거절됐다. 그 실제 로컬 출처 하나만 허용하도록 fixture를 수정했다. 첫 서버는 신원을 확인하고 종료했으며 생성 시각·시험 키·단계 수를 검증한 `showme-analysis-test-qobLoI`만 삭제했다. 두 번째 서버는 정상 종료 및 `PUBLICATION_UI_FIXTURE_REMOVED`를 확인했다. 다른 임시 폴더는 건드리지 않았다.
- 새 테스트의 readonly tuple 타입 오류를 수정한 뒤 타입 검사를 통과했다. 서버 DB 코드·migration은 이번 단계에서 변경하지 않았다. PostgreSQL 135개는 직전 단계의 검증이며 이번에 다시 실행했다고 표시하지 않는다.

## 남은 범위

Replit migration·기존 역할·Storage/운영 중지 조건 확인과 제한된 합성 실환경 시험, 기본 bootstrap 활성화 검토가 남는다. 미확인 원격 쓰기/게시 요청의 운영 해소, 실제 모바일·외부 수신자·카카오톡, 공유 미리보기 metadata, 별도 원본 opt-in은 완료하지 않았다. 원본 옵션은 계속 차단한다. 로컬 미커밋·미푸시이며 운영 배포/출시 완료가 아니다.
